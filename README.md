# Flutter To-Do App

A simple To-Do application built with Flutter and Dart to manage daily tasks.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Organize tasks into Study, Work, and Personal categories
- Search tasks
- Filter tasks by completion status and category
- Save tasks locally using SharedPreferences

## Technologies Used

- Flutter
- Dart
- SharedPreferences
- Material Design

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd flutter-todo-app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
